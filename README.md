
# ECA0905 – Digital Signal Processing (DSP) MATLAB Experiments

This repository contains MATLAB implementations of Digital Signal Processing (DSP) experiments performed as part of the ECA0905 course. The experiments cover IIR and FIR digital filters, finite word-length effects, multirate signal processing, speech processing, adaptive algorithms, biomedical signal processing, image processing, OFDM channel estimation, and beamforming.

## Experiments

### Experiment 1: Design, Realization and Performance Analysis of Butterworth IIR Low-Pass and High-Pass Digital Filters Using MATLAB
- Design and analyze Butterworth IIR low-pass and high-pass filters.

### Experiment 2: Design and Performance Analysis of Chebyshev Type-I IIR Low-Pass and High-Pass Filters Using MATLAB
- Design and evaluate Chebyshev Type-I low-pass and high-pass filters.

### Experiment 3: Design of IIR Filters Using Impulse Invariance and Bilinear Transformation Methods Using MATLAB
- Implement and compare impulse invariance and bilinear transformation methods for IIR filter design.

### Experiment 4: Design and Comparative Analysis of Butterworth, Chebyshev and Elliptic IIR Filters Using MATLAB
- Compare the characteristics and performance of Butterworth, Chebyshev, and elliptic filters.

### Experiment 5: Realization of IIR Filters Using Direct Form-I, Direct Form-II, Cascade and Parallel Structures Using MATLAB
- Implement IIR filters using different realization structures.

### Experiment 6: Design and Analysis of FIR Digital Filters Using Fourier Series and Windowing Techniques Using MATLAB
- Design FIR filters using Fourier-series and windowing approaches.

### Experiment 7: Design and Analysis of FIR Filters Using Parks–McClellan and Frequency-Sampling Techniques Using MATLAB
- Explore Parks–McClellan and frequency-sampling methods for FIR filter design.

### Experiment 8: Realization of FIR Filters Using Direct, Cascade and Linear-Phase Structures Using MATLAB
- Implement FIR filters using direct, cascade, and linear-phase structures.

### Experiment 9: Uniform Quantization and Finite Word-Length Effects in Digital Signal Processing Using MATLAB
- Demonstrate uniform quantization and analyze finite word-length effects.

### Experiment 10: Investigation of Coefficient and Product Quantization Noise and Limit-Cycle Oscillations Using MATLAB
- Investigate quantization noise and limit-cycle behavior in digital filters.

### Experiment 11: Investigation of Overflow Effects and Signal Scaling in Digital Filters Using MATLAB
- Analyze overflow, saturation, wrap-around, and signal scaling in fixed-point filtering.

### Experiment 12: Implementation and Performance Analysis of Decimation and Interpolation in Multirate Signal Processing Using MATLAB
- Implement decimation and interpolation and examine their signal and spectral behavior.

### Experiment 13: Polyphase Implementation of Decimation and Interpolation Filters Using MATLAB
- Implement polyphase filter branches and compare their output with conventional decimation.

### Experiment 14: 5G-Oriented Decimation and Interpolation for Multirate mmWave Signal Processing Using MATLAB
- Explore multirate filtering and sampling-rate conversion in a 5G-oriented baseband example.

### Experiment 19: Implementation of Spectral Subtraction for Speech Noise Reduction Using MATLAB
- Apply spectral subtraction to reduce noise in speech signals.

### Experiment 20: LPC-Based Speech Analysis and Vocoder Implementation Using MATLAB
- Analyze speech using Linear Predictive Coding (LPC) and demonstrate vocoder implementation.

### Experiment 21: Implementation and Performance Analysis of LMS and NLMS Algorithms for Adaptive Echo Cancellation and Equalization Using MATLAB
- Implement LMS and NLMS adaptive algorithms for echo cancellation and equalization.

### Experiment 22: Acquisition and Digital Signal Processing of ECG and EMG Signals Using Biomedical Signal Acquisition Systems
- Acquire or load biomedical signals, including electrocardiogram (ECG) and electromyogram (EMG) signals, for digital signal processing.
- Analyze biomedical signal characteristics using time-domain and frequency-domain representations.
- Apply suitable digital filtering techniques to reduce noise and unwanted signal components.
- Visualize the original and processed signals using MATLAB plots.
- Examine signal characteristics relevant to cardiac electrical activity and muscle electrical activity.

### Experiment 23: DSP-Based Image Enhancement, Compression and Edge Detection Using MATLAB
- Apply DSP techniques for image enhancement, compression, and edge detection.

### Experiment 24: OFDM Channel Estimation Using Least Squares and Minimum Mean Square Error Techniques Using MATLAB
- Implement and compare LS and MMSE channel-estimation techniques for OFDM.

### Experiment 25: FFT-Based Beamforming for 5G Wireless Communication Using MATLAB
- Demonstrate FFT-based beamforming concepts for 5G wireless communication.

## Requirements

- MATLAB or MATLAB Online.
- Signal Processing Toolbox may be required for functions used in filter design and signal analysis.
- Image Processing Toolbox may be required for image-processing functions in Experiment 23.
- Experiment 22 may require a compatible biomedical signal acquisition system and its associated software or drivers for live ECG/EMG acquisition. Alternatively, prerecorded signals can be used if supported by the experiment.
- Toolbox and hardware requirements depend on the functions and acquisition methods used by each experiment.

## How to Run

1. Open MATLAB or MATLAB Online.
2. Open the folder containing the required experiment files.
3. Open the corresponding `.m` file.
4. Ensure that required input files, helper functions, toolboxes, and hardware interfaces are available.
5. Run the script.
6. Review the Command Window results and generated plots.

Run each experiment separately. If a script uses helper functions, input signals, datasets, or external acquisition hardware, keep them in the locations expected by that script and configure the required inputs before execution.
